# Pagination

Python pagination project for Holberton School.

## Description

This project implements pagination for a dataset of popular baby names.

## Files

- `0-simple_helper_function.py` - index_range helper function
- - `1-simple_pagination.py` - Simple pagination with page and page_size
  - - `2-hypermedia_pagination.py` - Hypermedia pagination with metadata
    - - `3-hypermedia_del_pagination.py` - Deletion-resilient hypermedia pagination
